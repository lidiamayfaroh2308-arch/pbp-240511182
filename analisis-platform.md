
# Analisis Komparatif Platform Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, dan JavaScript untuk frontend. Backend dapat menggunakan .NET, PHP, JavaScript, Java, atau Python. | C++, C#, Java, dan Python. | Swift untuk iOS dan Kotlin untuk Android. Flutter dengan bahasa Dart juga dapat digunakan untuk pengembangan lintas platform. |
| Arsitektur | Memiliki frontend yang berjalan di browser dan backend yang mengelola logika, operasi, serta data. Keduanya berkomunikasi untuk menjalankan fungsi aplikasi. | Dipasang pada komputer dan berjalan tanpa browser. Aplikasi memanfaatkan sumber daya komputer, sistem operasi, file lokal, dan perangkat tambahan. | Dipasang pada smartphone atau tablet. Aplikasi dapat memanfaatkan fitur perangkat dan menggunakan backend untuk mengirim atau menerima data yang tidak disimpan secara lokal. |
| Cara distribusi | Diakses melalui browser menggunakan URL tanpa perlu instalasi. Pembaruan dilakukan melalui server. | Diunduh dan dipasang langsung pada komputer melalui file instalasi atau saluran distribusi perangkat lunak. | Diunduh dan dipasang melalui Google Play Store, Apple App Store, atau saluran distribusi pengembang. |
| Keunggulan | Dapat diakses dari berbagai perangkat melalui browser, tidak perlu instalasi, mudah dibagikan melalui tautan, dan pembaruannya dapat dilakukan secara terpusat. | Mendukung penggunaan offline, dapat memanfaatkan sumber daya komputer secara optimal, serta memiliki akses lebih luas ke sistem operasi, file, dan perangkat tambahan. | Mendukung interaksi layar sentuh, dapat menggunakan kamera, GPS, sensor, notifikasi, mudah ditemukan di toko aplikasi, serta dapat menyediakan fungsi offline tertentu. |
| Keterbatasan | Fungsi offline dapat terbatas, akses ke fitur perangkat tidak selalu lengkap, dan perbedaan browser dapat memengaruhi tampilan atau cara kerja aplikasi. | Membutuhkan instalasi dan pembaruan secara rutin. Aplikasi juga dapat terbatas pada perangkat tertentu dan memerlukan versi berbeda untuk sistem operasi yang berbeda. | Pengembangan untuk Android dan iOS dapat membutuhkan sumber daya tambahan. Distribusi melalui toko aplikasi juga melibatkan persyaratan dan proses persetujuan. |
| Contoh aplikasi | Facebook Web, Zara Web, dan eBay Web. | Microsoft Excel, Adobe Photoshop, dan QuickBooks Desktop. | Facebook Mobile, Instagram, TikTok, dan Uber. |

## Refleksi

Menurut saya, platform yang paling menarik untuk dipelajari adalah Web karena aplikasi web bisa digunakan untuk banyak hal, misalnya mengelola data, mengirim pesan, dan membuat desain. Saya penasaran bagaimana aplikasi seperti Canva dan Gmail bisa berjalan melalui browser tanpa harus memasang aplikasinya di laptop. Saya juga ingin belajar bagaimana cara membuat aplikasi web menggunakan HTML, CSS, dan JavaScript.

Tantangan terbesar saat setup environment adalah memastikan seluruh perangkat lunak dan tools yang dibutuhkan sudah terpasang dan dikonfigurasi dengan benar. Contohnya saya perlu memastikan  VS Code dan GitHub sudah terpasang, dan mengenal cara kerja VS Code dan GitHub, karena keduanya memiliki fungsi yang berbeda. VS Code digunakan untuk membuat dan mengedit file, sedangkan GitHub digunakan untuk menyimpan tugas secara online.

Untuk mengatasi tantangan tersebut, saya akan mempelajari cara menggunakan setiap aplikasi dengan mengikuti panduan yang tersedia. Saya juga akan mencoba mempraktikkan langsung apa yang sudah dipelajari agar lebih mudah dipahami. Jika ada kendala, saya akan mencari tahu penyebabnya melalui tutorial atau sumber lain. jadi saya bisa lebih terbiasa menggunakan aplikasi yang diperlukan dan tidak mengalami kesulitan yang sama saat mengerjakan tugas berikutnya.
